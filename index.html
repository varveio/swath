swath

Parallel, resumable S3 listing for very large buckets.

For when you need every key in a bucket too big to list one page at a time — and there's no fresh S3 Inventory to fall back on. Swath lists; it never reads object contents.

It divides the unknown keyspace into guessed ranges, corrects the guesses while it lists, and writes JSONL, TSV, or crash-resumable Parquet.

First run · a real public bucket

Verify Swath with one day of NOAA model output

docker run --rm ghcr.io/varveio/swath:latest \
  list s3://noaa-gestofs-pds/estofs.20210101/ \
  --region us-east-1 --no-sign-request --format tsv > /dev/null

Docker required; no Swath or JDK installation. This public prefix contains about 5,200 objects and lists anonymously in a few seconds. Object rows are discarded; the summary reports objects, time, API calls, and estimated request cost. No AWS account or credentials are needed.

This small slice checks installation and connectivity, not scale. It comes from the same NOAA bucket as the recorded 39.7M-object run below. The maintained install and quickstart guide shows how to keep the result as crash-resumable Parquet.
