# The NOAA run trace has moved

This page showed the trace of one swath 0.3 listing of the public bucket `s3://noaa-gestofs-pds`. It belongs to
that release and is no longer published here.

- List a prefix of the same bucket yourself, with no account:
  [Try a public bucket](https://swath.varve.io/#try-a-public-bucket). Dated runs of swath 0.4 are in
  [the measurements](../../docs/internals/measurements.md).
- The trace as it was published: `runs/noaa-gestofs-pds/index.html` in
  [the site's source before the redesign](https://github.com/varveio/swath/tree/c34d7b5ed140c27a847c8ab6bd6ae7f6bc9a2518/site).
