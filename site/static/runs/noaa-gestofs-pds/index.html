§1

The guesses, and how they turned out

Before any range lists, swath asks the store where the folders are — a few delimiter=/ listings of the top of the tree — and cuts the keyspace at them into starting ranges. A folder name says nothing about how many objects are behind it, so this is a guess, and it is the only cheap information the engine will get.

§4

The whole run, on one map

Horizontal is the keyspace weighted by objects — equal width means an equal number of objects — and vertical is time running downward. Each rectangle is one range over the slice it owned and the time it owned it, colored by which original seed guess it descends from. Because width is objects, a rectangle's area is roughly the work it did.

Wide and short is a big slice eaten fast. A tall thin column is a serial tail — a dense region that could not be divided, outliving everything around it.

§5

Watch it happen

The same events replayed in order, on the same axis. Bands are live ranges, filled to each worker's cursor; ticks are split pivots as they commit. A split ends its range at the cursor and hands the rest on as two new ranges.
